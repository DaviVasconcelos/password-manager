# PasswordManager

Gerenciador de senhas local desenvolvido em C#/.NET 8 utilizando Clean Architecture.

## Objetivo

Projeto para demonstrar conhecimentos em:

- Clean Architecture
- Criptografia aplicada
- EF Core
- WinUI 3
- Testes automatizados
- CI/CD
- Boas práticas de engenharia

## Stack

- .NET 8
- WinUI 3
- SQLite
- EF Core
- AES-256-GCM
- Argon2id
- xUnit
- FluentAssertions
- Serilog
